| Função | Resultado |
|---|---|
| `Str::upper($value)` | CONTEUDO |
| `Str::lower($value)` | conteudo |
| `Str::title($value)` | Conteudo Exemplo |
| `Str::ucfirst($value)` | Conteudo exemplo |
| `Str::ucsplit($value)` | Separa palavras iniciadas em maiúsculas |
| `Str::trim($value)` | Remove espaços das extremidades |
| `Str::replace('a', 'b', $value)` | Substitui caracteres |
| `Str::remove('a', $value)` | Remove ocorrências de um caractere |
| `Str::squish($value)` | Remove espaços extras |
| `Str::stripTags($value)` | Remove tags HTML |
| `Str::slug($value)` | Meu Texto → meu-texto |
| `Str::snake($value)` | MeuTexto → meu_texto |
| `Str::camel($value)` | meu_texto → meuTexto |
| `Str::studly($value)` | meu_texto → MeuTexto |
| `Str::headline($value)` | meu_texto → Meu Texto |
| `Str::kebab($value)` | MeuTexto → meu-texto |
| `Str::contains($value, 'texto')` | Verifica se contém determinado texto |
| `Str::startsWith($value, 'texto')` | Verifica se começa com determinado texto |
| `Str::endsWith($value, 'texto')` | Verifica se termina com determinado texto |
| `Str::is($pattern, $value)` | Verifica se corresponde a um padrão |
| `Str::length($value)` | Retorna o tamanho do texto |
